# Развёртывание и обслуживание (Cloudflare Workers + D1 + R2)

Ученики, группы, преподаватели, расписание, планы уроков с аудио и документами, словарь, баллы,
магазин, мини-игры, оплаты, анкеты. Всё работает на бесплатном тарифе Cloudflare:

| Часть | Сервис Cloudflare | Бесплатный лимит |
|---|---|---|
| Сайт (HTML, CSS, JS) | Workers Static Assets | без ограничений |
| Сервер (вход, данные, права) | Workers | 100 000 запросов в сутки, 10 мс процессора на запрос |
| База данных | D1 (SQLite) | 500 МБ на базу, 5 млн чтений строк в сутки |
| Аудио, Word, фото | R2 | 10 ГБ, скачивание бесплатно |

Коммерческое использование на бесплатном тарифе Cloudflare разрешено.

---

## Как устроено

```
public/            сайт (как раньше: index.html, css/, js/)
src/worker.js      сервер: /api/* — данные и вход, /files/* — файлы уроков (только после входа)
src/api/           обработчики API
src/lib/           логика: права ролей, синхронизация, баллы, пароли, работа с D1 и R2
migrations/        схема базы
tools/             перенос данных и файлов, сброс пароля
dev/               локальный запуск без интернета
tests/             автотесты
```

* Пароли хранятся только в зашифрованном виде (PBKDF2), проверяет их сервер. Сессия хранится в защищённой cookie на 60 дней.
* Ученик видит только свои личные данные. Телефоны, PIN-коды и родителей одноклассников сервер ему не отдаёт.
* Баланс баллов считает сервер. Ученик может получить баллы только за анкету (один раз), день рождения
  (раз в год) и мини-игры (лимит в неделю), а покупать — только при достаточном балансе.
* Файлы уроков открываются только после входа на сайт.
* Изменения с разных устройств сливаются по полям, не затирая друг друга. Другие устройства видят их
  через 15 секунд (сотрудники) или 30 секунд (ученики), а также сразу при переключении на вкладку.

## Установка и перенос (Windows)

Понадобится: [Node.js](https://nodejs.org) версии 22.13 или новее (LTS), бесплатный аккаунт Cloudflare.
Желательно [ffmpeg](https://www.gyan.dev/ffmpeg/builds/) (`winget install ffmpeg`): он сожмёт WAV-аудио в MP3 примерно в 10 раз.

Все команды выполняются в папке проекта (`stepup-cloudflare`) в PowerShell или «Командной строке».

### 1. Подготовка
```powershell
npm install
npx wrangler login
```
Откроется браузер: войдите в Cloudflare и разрешите доступ.

### 2. База данных и хранилище файлов
```powershell
npx wrangler d1 create stepup
```
Скопируйте из вывода `database_id` и вставьте его в `wrangler.jsonc` вместо `PASTE-DATABASE-ID-HERE`.

```powershell
npx wrangler r2 bucket create stepup-files
```
Если Cloudflare попросит включить R2: панель Cloudflare → **R2 Object Storage** → **Enable**.
Он может попросить привязать карту даже для бесплатного объёма. Списаний не будет, пока вы в пределах 10 ГБ.

### 3. Подготовка данных из резервной копии
Свежая копия нужна прямо перед переездом. На **старом сайте** войдите администратором → **Экспорт данных**.
Затем:
```powershell
node tools/prepare-migration.mjs --backup "C:\путь\к\english_crm_backup.json" --uploads "C:\путь\к\папке\uploads"
```
Скрипт:
* переносит всех учеников, группы, баллы, оплаты, расписание и все уроки с домашками и словами;
* сохраняет пароли преподавателей и администратора (теперь в зашифрованном виде) и PIN-коды учеников — **старые памятки работают**;
* заменяет ссылки на файлы `/uploads/...` на новые `/files/lessons/...`;
* сжимает WAV в MP3, если установлен ffmpeg;
* создаёт `data/migration/import.sql` (база) и `data/migration/files.json` (список файлов).

Загрузите базу в Cloudflare:
```powershell
npx wrangler d1 execute stepup --remote --file=data/migration/import.sql
```

### 4. Публикация сайта
```powershell
npx wrangler deploy
npx wrangler secret put SESSION_SECRET
```
На запрос секрета вставьте длинную случайную строку (32+ символа, например из любого генератора паролей).
После `deploy` будет показан адрес сайта, вида `https://stepup-english.<ваше-имя>.workers.dev`.

### 5. Загрузка файлов уроков
```powershell
node tools/upload-files.mjs --site https://stepup-english.<ваше-имя>.workers.dev --login admin
```
Скрипт спросит пароль администратора и загрузит файлы в R2. Если связь оборвётся, просто запустите
команду ещё раз: уже загруженные файлы пропускаются.

### 6. Проверка и переключение
* Войдите администратором (пароль прежний) и смените его кнопкой **🔑 Пароль** на дашборде.
* Откройте учебник, урок, аудио; войдите учеником по памятке.
* После переезда закройте старую базу Firebase: Firebase Console → Firestore → Rules →
  `allow read, write: if false;`. Сейчас её может прочитать любой, кто знает публичный ключ сайта,
  а в ней пароли преподавателей открытым текстом.

Свой домен (по желанию): панель Cloudflare → Workers → `stepup-english` → **Settings → Domains & Routes**.

## Повседневная работа

* **Пароль администратора:** кнопка «🔑 Пароль» на дашборде.
* **Пароли преподавателей:** «Преподаватели → Редактировать».
* **Забыли пароль администратора:** `node tools/set-password.mjs admin НовыйПароль`.
* **Резервная копия:** дашборд → «Экспорт данных». Сохраняйте копию раз в неделю.
  Восстановление: `node tools/prepare-migration.mjs --backup копия.json`, затем шаг 3 (`wrangler d1 execute`).
  Кнопка «Восстановить из копии» подходит только для небольших баз.
* **Обновить сайт после изменений в коде:** `npx wrangler deploy`.
* **QR-коды:** новые памятки содержат ID и PIN. Когда раздадите их всем, запретите вход по старым QR (только ID):
  `npx wrangler secret put ALLOW_LEGACY_QR` → `0`.

## Локальный запуск

```powershell
npm run dev        # http://localhost:8787, данные в папке data/
npm test
```
Перенести копию в локальную версию: `node tools/prepare-migration.mjs --backup ... --uploads ... --local`.

## Ограничения

* Формат **WMA** браузеры не воспроизводят. Загружайте MP3: WMA будет доступен только для скачивания.
* Максимальный размер одного файла — 95 МБ (лимит запроса на бесплатном тарифе).
* Разбор Word-файлов со словами и списками учеников выполняется в браузере.
* Если лимиты бесплатного тарифа станут тесными, тариф Workers Paid стоит 5 $ в месяц:
  10 млн запросов, 30 секунд процессора на запрос.
